🎬 Movie Recommendation System

A Movie Recommendation System built using Python and Streamlit that helps users discover movies based on their selected preferences.

🚀 Project Overview

The Movie Recommendation System provides personalized movie suggestions through an interactive web application. It uses a precomputed movie similarity model to identify and recommend similar movies.

✨ Features

- 🎥 Search and select movies.
- 🍿 Get top 5 recommended movies.
- 🖼️ Display movie posters.
- ⚡ Fast recommendations using precomputed similarity scores.
- 🌐 Interactive and user-friendly Streamlit interface.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Pillow (PIL)
- Pickle

⚙️ Installation and Setup

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Navigate to the project folder

cd Movie-recommendation-System

Step 3: Install dependencies

pip install -r requirements.txt

Step 4: Run the application

streamlit run app.py

🌐 Deployment

The application can be deployed using Streamlit Community Cloud.
